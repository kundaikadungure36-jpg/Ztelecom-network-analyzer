# Z Telecom Network Analyzer - Econet AI Portfolio

A Python tool that analyzes telecom site performance and flags high-latency sites needing attention. Built for Econet AI Network Engineer application.

**What it does:**
- Analyzes network site data (Harare CBD, Kuwadzana, etc.)
- Flags latency >100ms as ALERT
- Generates CSV report for NOC team

**Tech:** Python, Pandas
**Built by:** Diploma in Telecommunications, Harare
**Goal:** Next step is adding AI to predict outages before they happen.

## How to run
python analyzer.py
